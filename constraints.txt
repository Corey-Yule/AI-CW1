Part 1A

Variables:
Each square on the sudoku. (81 vars -> 9x9)
Domains:
The 3x3 grids have to have the values between 1-9.
If a square is already filled in, then its domain is set to that value.
Constraints:
No adjacent row can have the same number within the 9x9
No adjacent column may have the same number within the 9x9
And within the 3x3 all the numbers must span from 1-9 meaning there can be no duplicates.
